Perfect isolator:
\(\sigma = 0\);
\(V = IR\)

For steady currents and uniform conductivity:

\(\bm \nabla \cdot \bm E = \frac{1}{\sigma} \bm \nabla \cdot \bm J = 0\)

emf of self inductance:

\secblock{H12 Electrodynamics and Relativity}

Einstein velocity addition formula:

\(v_{ab} = \frac{v_a + v_b}{1 + \frac{v_a v_b}{c^2}}\)

Time dilation:
\(\Delta t_{obs} = \gamma \Delta t_0\)

Length contraction:
\(\Delta x_{obs} = \frac{\Delta x_0}{\gamma}\)

Lorentz factor:
\(\gamma = \frac{1}{\sqrt{1 - \frac{v^2}{c^2}}}\)

\(\gamma = \cosh\theta\); \(\gamma\beta = \sinh\theta\)

\(\cosh^2\theta - \sinh^2\theta = 1\); \(\theta = \tanh^{-1} \beta\)

Lorentz transformation:

\(\begin{cases}
    t' = \gamma (t -  \frac{v x}{c^2}) \\
    x' = \gamma (x - vt) \\
    y' = y \\
    z' = z
\end{cases}
\begin{cases}
    t = \gamma (t' + \frac{v x'}{c^2}) \\
    x = \gamma (x' + vt') \\
    y = y' \\
    z = z'
\end{cases}\)

\(x_0 \equiv ct\) and \(\beta \equiv \frac{v}{c}\)

Einstein summation convention:

\(\sum_{\mu=0}^3 a^\mu b_\mu = a^\mu b_\mu\)

Proper time:
\(d\tau = \sqrt{1 - \beta_u^2}dt\)

Proper velocity:
\(\bm \eta = \frac{d\bm l}{d\tau} = \gamma \bm u\) 

Ordinary velocity:
\(\bm u = \frac{d\bm l}{dt}\)

\(\eta_0 = \frac{dx^0}{d\tau} = c \frac{dt}{d\tau}\);
\(\eta'^\mu = \Lambda_\nu^\mu \eta^\nu\)

\(\bm u'_\parallel = \frac{\bm u_\parallel-\bm v}{1 - u_\parallel v/c^2}\) ; \(\bm u'_\perp = \frac{\bm u_\perp}{\gamma (1 - u_\parallel v/c^2)}\)

Relativistic momentum:
\(\bm p \equiv  m \eta =  \gamma m \bm u\)

\(p^0 = m\eta^0 = \gamma mc\)

\(\eta_\mu \eta^\mu = - \gamma^2 c^2 + \gamma^2 u^2 = -c^2\gamma^2(1-\beta_u^2) = -c^2\)

\(p^\mu p_\mu = -(p^0)^2+ (\bm p \cdot \bm p) = -m^2c^2\)



Relativistic energy:
\(E \equiv \gamma mc^2\) ;
\(E_{rest}=mc^2\)



Comton wavelength shift:
\(\lambda = \lambda_0 + \frac{h}{mc}(1-\cos \theta)\)

Relativistic dynamics:
\(\bm F = \frac{d\bm p}{dt} = m \frac{d\eta}{dt}\)

Work-energy theorem:
\(W = \Delta E = E_f - E_i\) ; \(\frac{d\bm p}{dt} \cdot \bm u = \frac{dE}{dt}\);
\(\frac{d(\gamma \bm u)}{dt}\bm u = c^2\frac{d\gamma}{dt}\)

\(\bm F'_{\perp} = \frac{1}{\gamma} \bm F_{\perp}\) ; \(\bm F'_{\parallel} = \bm F_{\parallel}\)

\(\bm K = \frac{d}{d\tau} \frac{d\bm p}{dt} = \gamma \bm F\) ; \(K^0 = \frac{dp^0}{d\tau} = \frac{1}{c} \frac{dE}{d\tau}\)

Total momentum:

\(\bm P = M \frac{d \bm R_m}{dt}\) ; CM: \(R_m = \frac{1}{M} \sum_i m_i r_i\);

\(\bm P = \frac{E}{c^2} \frac{d\bm R_e}{dt}\) ;  C Energy: \(R_E = \frac{1}{E} \sum_i E_i r_i\)

\(\bm p = \frac{1}{c^2} (\bm m\times \bm E )\)

\(\bm F = \frac{m}{\sqrt{1-u^2/c^2}}[\bm a + \frac{\bm u (\bm u \cdot \bm a)}{c^2-u^2}]\)

\(\bm a = \frac{d\bm u}{dt}\)

\(\bm \alpha^\mu \equiv \frac{d\eta^\mu}{d \tau} = \frac{d^2 x^\mu}{d \tau^2}\)

\(\gamma_{tot} = \gamma_1 \gamma_2 (1 + \beta_1 \beta_2)\)

\(v_\pm = \frac{v \mp u}{1 \mp vu/c^2}\) ; \(\gamma_\pm = \frac{1}{\sqrt{1 - v_\pm^2/c^2}}\)

Field transformation in the x-direction:

\begin{cases}
