# Over de kleuren van tijdstempels op GitHub

Als je naar deze repository kijkt op GitHub's website, zie je misschien dat sommige bestanden **rode** of **oranje** tijdstempels hebben bij "Last updated" of "Last modified".

## Dit is normaal gedrag van GitHub!

GitHub gebruikt verschillende kleuren om aan te geven hoe lang geleden een bestand voor het laatst is gewijzigd:

- **Groen/Normale kleur**: Recent gewijzigde bestanden (binnen enkele dagen/weken)
- **Oranje**: Bestanden die al een tijdje niet zijn bijgewerkt (enkele weken tot maanden)
- **Rood**: Bestanden die al langere tijd niet zijn bijgewerkt (maanden of langer)

## Waarom doet GitHub dit?

Deze visuele indicator helpt om snel te zien:
- Welke delen van de repository actief worden onderhouden
- Welke bestanden mogelijk verouderd zijn
- Welke directories recent activiteit hebben gehad

## Is dit een probleem?

**Nee!** Dit is gewoon een hulpmiddel van GitHub om je te helpen de "frisheid" van bestanden in te schatten. Het betekent NIET dat:
- Er iets fout is met je repository
- De bestanden beschadigd zijn
- Je iets moet repareren

## Wat kun je eraan doen?

Als je wilt dat alle bestanden "groene" tijdstempels hebben:
1. Werk de bestanden bij wanneer nodig voor je cursus
2. Commit en push de wijzigingen naar GitHub
3. De tijdstempels worden automatisch bijgewerkt met nieuwe kleuren

Maar nogmaals: **het is niet nodig om dit te doen**. De kleuren zijn alleen informatief!

## About Timestamp Colors on GitHub (English)

When viewing this repository on GitHub's website, you may notice that some files have **red** or **orange** timestamps next to "Last updated" or "Last modified".

## This is normal GitHub behavior!

GitHub uses different colors to indicate how long ago a file was last modified:

- **Green/Normal color**: Recently modified files (within days/weeks)
- **Orange**: Files that haven't been updated for a while (weeks to months)
- **Red**: Files that haven't been updated for a longer time (months or more)

## Why does GitHub do this?

This visual indicator helps you quickly see:
- Which parts of the repository are actively maintained
- Which files might be outdated
- Which directories have had recent activity

## Is this a problem?

**No!** This is simply a GitHub tool to help you assess file "freshness". It does NOT mean that:
- Something is wrong with your repository
- The files are corrupted
- You need to fix anything

## What can you do about it?

If you want all files to have "green" timestamps:
1. Update the files when needed for your course
2. Commit and push the changes to GitHub
3. The timestamps will automatically update with new colors

But again: **you don't need to do this**. The colors are only informational!
